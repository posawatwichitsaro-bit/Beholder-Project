## เปิดโต๊ะ

เปิด Docker Desktop แล้วรันคำสั่งจากโฟลเดอร์นี้

```sh
docker compose up --build --detach --wait
```

เปิด [Beholder บนเครื่องนี้](http://127.0.0.1:3000/) เลือก **สร้างบัญชี** เพื่อสมัครด้วยอีเมล รหัสผ่านอย่างน้อย 8 ตัวอักษร และชื่อตัวละครที่จะแสดงบนโต๊ะ จากนั้นตั้งชื่อห้องแล้วสร้างห้อง DM เปิดเมนู **เชิญผู้เล่น** เพื่อคัดลอกลิงก์ ผู้เล่นจะเข้าด้วยบัญชีหรือใช้ชื่อชั่วคราวแบบ Guest ก็ได้

แก้ชื่อตัวละครที่แสดงบนโต๊ะได้จาก **☰ → ตั้งค่าบัญชี** ชื่อใหม่จะอัปเดตในห้องที่เข้าด้วยบัญชีนี้ ส่วนชื่อบน Character Sheet จัดการผ่านชีตโดยตรง ห้องที่เคยเปิดหรือเข้าผ่านบัญชีกลับเข้าได้ด้วย URL ห้องหลังเข้าสู่ระบบอีกครั้ง รวมถึงจากเบราว์เซอร์ใหม่

สำหรับกลุ่มที่อยู่บนเครือข่ายเดียวกัน ตั้งค่า `BEHOLDER_BIND=0.0.0.0` ในไฟล์ `.env` ข้าง Compose แล้วเปิดเว็บด้วย IP ของเครื่องที่รัน Docker ก่อนกดคัดลอกลิงก์ ลิงก์เชิญจะใช้ที่อยู่เดียวกับหน้าเว็บ ค่าตั้งต้นเปิดให้เข้าจากเครื่องที่รัน Docker เท่านั้น

กด **☰ เมนูโต๊ะ** ทางซ้ายเพื่อเปิดฉากและแผนที่ ชีต ลูกเต๋า การต่อสู้ Object หรือคลังส่วนตัว กด Escape หรือคลิกพื้นที่นอกเมนูเพื่อกลับมากางฉากเต็มพื้นที่ หมุนล้อเมาส์เพื่อซูมที่ตำแหน่งตัวชี้ กดล้อเมาส์ค้างแล้วลากเพื่อเลื่อนกระดาน กด R เพื่อวัดระยะ หรือกด V เพื่อกลับมาเลือก Token จากนั้นลากซ้ายบนช่องว่างเพื่อครอบเลือกหลาย Token แล้วลาก Token ในกลุ่มเพื่อย้ายพร้อมกัน

ใน **ฉากและแผนที่** DM สร้างฉาก อัปโหลดแผนที่ PNG/JPEG/WebP แล้วตั้งขนาดช่องและจุดกำเนิด Grid ใช้ **เปิดให้ผู้เล่น** เพื่อสลับฉากของทั้งโต๊ะ ใน **ชีตในห้อง** ผู้เล่นกด **วาง** ข้างชีตของตัวเองในฉากที่เปิดอยู่ หรือเลือก **วาง Token** จากคลังชีตส่วนตัว ส่วน DM วางชีตผู้เล่นและต้นแบบมอนสเตอร์ได้

ตอนวางชีตตัวละคร เลือก **Character Token** สำหรับตัวละครหลักหนึ่งตัวต่อผู้เล่นต่อฉาก หรือ **Companion Token** สำหรับผู้ร่วมทางที่มีชีตของตัวเอง ผู้เล่นกดปุ่มลูกศรเพื่อขยับตัวละครหลักทีละ 1 ช่องได้ระหว่างเล่นและระหว่าง Encounter และใช้เมาส์ลาก Companion ได้ กดชื่อข้างปุ่มลูกศรบนกระดานเพื่อจัดกล้องกลับมาหาตัวละครหลัก คลิกขวาที่ Token ของตัวเองเพื่อเปลี่ยนบทบาท หากตั้ง Companion เป็นตัวหลัก ตัวหลักเดิมจะกลายเป็น Companion

ใช้ **↑ / ↓** ข้างชื่อเพื่อจัดลำดับฉาก เลือกฉากแล้วกด **คัดลอกฉาก** เพื่อตั้งชื่อสำเนาที่มีแผนที่ Grid, Token และ Object เดิม Token ตัวละครผู้เล่นใช้ชีตเดียวกัน มอนสเตอร์และ Object เป็นสำเนาแยก และ Encounter เริ่มใหม่เมื่อ DM พร้อม หากลบฉากที่เปิดอยู่ ระบบเปิดฉากถัดไปตามลำดับ หรือฉากก่อนหน้าหากไม่มีฉากถัดไป

คลิกขวาที่ช่องว่างเพื่อเลือกจุดวาง Token เปิดลูกเต๋า หรือเลือกเครื่องมือวัดระยะ คลิกขวาที่ Token เพื่อเปิดชีตตามสิทธิ์ DM ปรับ HP หรือเอา Token ออกจากฉากได้ เมนู **⋯** บนแถบเครื่องมือเปิดคำสั่งชุดเดียวกันสำหรับ Token ที่เลือกหรือกระดาน

- **บทบาท** หน้าเข้าร่วมมีตัวเลือก DM และ Player ลิงก์ผู้เล่นใช้กับ Player ส่วนลิงก์สำหรับ DM ออกได้จาก **ฉากและแผนที่ → เชิญ DM** และใช้ได้ครั้งเดียว
- **รูปและ HP** เพิ่มรูปที่ **แก้ชีต → รูปตัวละครบน Token** รองรับ PNG, JPEG และ WebP รูปกับแถบ HP อัปเดตบนกระดานตามข้อมูลชีต แถบสีฟ้าบางแสดง Temporary HP
- **ผลทอย** ถาดมุมล่างขวาแสดงรายการล่าสุดของโต๊ะ DM ปิดถาดเฉพาะหน้าจอตัวเองและเปิดอีกครั้งจากเมนู **ลูกเต๋า** ได้ ตัวเลือก **ทอยลับ** จำกัดการเห็นผลไว้กับ DM ที่กดทอย
- **Encounter ตัวอย่าง** ใน **ฉากและแผนที่** ให้ DM กด **เพิ่ม Encounter ด่านร้างริมทาง** แล้วเปิดฉากให้ผู้เล่น วาง Token ตัวละครของกลุ่ม และเริ่ม Initiative จากเมนู **การต่อสู้**

### Object และ Inventory

DM คลิกขวาบนช่องว่างแล้วเลือก **นำเข้า Object ที่นี่** หรือเปิดเมนู **Object** เพื่อกำหนดตำแหน่ง ขนาด รูป และประเภท Object คลิกขวาที่ Object เพื่อเปิดคำสั่งของประเภทนั้น ผู้เล่นให้ Token ที่ควบคุมยืนติด Object ก่อนหยิบของ ฝากของ หรือโจมตีสิ่งก่อสร้าง

เปิด **คลังส่วนตัว → Object** เพื่อสร้าง แก้ไข หรือลบต้นแบบ เช่น เต็นท์หรือสิ่งก่อสร้าง DM ยังเปิด Object บนกระดานแล้วกด **คัดลอก Object เข้าคลังส่วนตัว** ได้ คลังผูกกับบัญชีและใช้ซ้ำได้ทุกห้องของผู้ใช้ โดย DM กด **วางในฉาก** แล้วคลิกช่องบนกระดาน การโต้ตอบกับสำเนาที่วางแล้วและการแก้ต้นแบบมีผลแยกกัน

| ประเภท | การโต้ตอบ |
| --- | --- |
| กล่อง | เปิดหรือปิด ตั้งล็อกและ DC สะเดาะล็อก หยิบของเข้าตัวละคร หรือฝากของจาก Inventory |
| ของประกอบฉาก | ตรวจรายละเอียดหรือเปิดดูภาพ |
| สิ่งก่อสร้าง | ทอยโจมตีเทียบ AC หรือให้ DM หัก HP เมื่อยังมี HP ระบบคิดที่กำบังจากเส้นระหว่างจุดกึ่งกลาง Token ของผู้โจมตีกับเป้าหมาย |
| ไอเทม | เก็บจากฉากเข้า Inventory ของตัวละคร |

Inventory แยกตามตัวละครและมอนสเตอร์แต่ละตัว เปิดได้จากชีต เมื่อคัดลอกชีตเข้าคลังส่วนตัว ระบบจะบันทึกรายการของ ณ เวลานั้นพร้อมชีต การนำกลับเข้าห้องสร้างสำเนาแยกให้ตัวละครในห้องนั้น

**ค้นศพและ Loot** ใน Monster Sheet เพิ่มของพื้นฐานและของโบนัส พร้อมตั้ง DC และเลือก Investigation หรือ Perception DM ปรับของและ DC ได้จากเมนูคลิกขวาที่ศพก่อนค้น ผู้เล่นขยับ Token ของตนมาอยู่ติดศพ แล้วเลือก **ค้นศพ / Loot** ผลถึง DC จะได้รับของทั้งสองกลุ่ม ผลต่ำกว่า DC จะได้รับเฉพาะของพื้นฐาน ค้นได้หนึ่งครั้งต่อศพ และของจะเข้า Inventory ของตัวละครที่ค้น

**สะเดาะกล่อง** DM ติ๊ก **ล็อกกล่อง** ตอนนำเข้า หรือเปิดกล่องจากเมนูคลิกขวาเพื่อตั้งล็อกภายหลัง ค่าเริ่มต้นคือ DC 15 ผู้เล่นต้องนำ Token มาติดกล่องและมีไอเทมประเภท **Thieves’ Tools** จากนั้นทอย Dexterity ตามความชำนาญที่ตั้งไว้ในชีต ตัวละครแต่ละตัวลองได้ครั้งเดียวต่อล็อกจนกว่า DM จะตั้งล็อกใหม่ DM กด **ปลดล็อกและเปิดทันที** ได้

กติกาทอยอ้างอิง [D&D Beyond Basic Rules](https://www.dndbeyond.com/sources/dnd/br-2024/playing-the-game) และ [Thieves’ Tools](https://www.dndbeyond.com/sources/dnd/br-2024/equipment) ระบบ Loot ที่แยกของพื้นฐานกับโบนัสและจำกัดการค้นต่อศพเป็นกติกาของ Beholder

### แผงต่อสู้ของ DM

เปิด **เตรียมการต่อสู้** บนกระดาน หรือเลือก **การต่อสู้** ในเมนูโต๊ะ เลือกผู้ร่วมต่อสู้แล้วทอย Initiative แผงข้างกระดานจะแสดงตัวที่กำลังเล่นและตัวถัดไป คลิก Token หรือลำดับเทิร์นเพื่อเลือกเป้าหมาย เลือกอาวุธและรูปแบบการทอย แล้วกด **โจมตี**

เมื่อโจมตีโดน ให้ทบทวนหรือแก้จำนวนใน **ผลรอจัดการ** แล้วกด **หัก HP** หากจะไม่ใช้ผลนั้น กด **ข้ามผล** เปิดคำสั่ง **ปรับ HP** สำหรับการรักษาหรือกำหนด HP ชั่วคราว และเปิด **เวทมนตร์ ทดสอบ และจัดการช่องเวท** เมื่อต้องร่ายเวทหรือเรียกทอยอื่น ๆ กด **เทิร์นถัดไป** เพื่อส่งต่อ ระบบข้ามผู้ที่เสียชีวิตและจะแจ้งให้ยืนยันหากยังมีผลค้าง

เมื่อ Encounter เริ่มแล้ว DM และผู้เล่นที่มีตัวละครร่วมต่อสู้จะเห็น **Turn Initiative** ทางซ้าย ตัวที่กำลังเล่นมีกรอบเรืองแสง คลิกภาพ Token เพื่อจัดกล้องของตัวเองให้ Token อยู่กลางกระดาน เลือกประเภทความเสียหายก่อนหัก HP เพื่อให้ตัวเลขที่ลอยเหนือ Token ใช้สีของประเภทนั้น

ใน **โจมตีแบบ AoE** ให้ DM เลือกวงกลม สี่เหลี่ยม กรวย หรือเส้น แล้วลากบนกระดาน เส้นกว้างหนึ่งช่อง พื้นที่ใช้จุดกึ่งกลาง Token เป็นเกณฑ์เสนอเป้าหมาย ตรวจรายชื่อ ตั้งผลเต็ม ครึ่งหนึ่ง หรือข้ามตามการตัดสินของโต๊ะ แล้วกด **ทอยและใช้ความเสียหาย AoE** ระบบทอยความเสียหายครั้งเดียวและใช้กับเป้าหมายตามที่เลือก

### คลังส่วนตัว

เมื่อเข้าสู่ระบบด้วยอีเมล ให้เปิด **☰ → คลังส่วนตัว** เพื่อสร้าง Character Sheet หรือ Custom Monster หรือกด **คัดลอกเข้าคลังส่วนตัว** จากชีตในห้อง หากใช้โปรไฟล์คลังแบบเดิม ให้เข้าคลังด้วยชื่อและรหัสผ่านเดิมขณะเล่นแบบ Guest

ปุ่ม **ใช้ในห้องนี้** สร้างสำเนาชีตในห้องปัจจุบัน DM นำ Custom Monster เข้าเป็นต้นแบบของห้องได้ การแก้ HP และข้อมูลระหว่างเล่นมีผลกับสำเนาในห้อง เมื่อต้องการเก็บเวอร์ชันจากการเล่น ให้คัดลอกเข้าคลังอีกครั้ง

### คำนวณค่าสถานะและนำเข้า Character Sheet

เปิด **ชีตในห้อง → + ตัวละคร** หรือสร้างชีตใหม่ในคลังส่วนตัว แล้วเลือก **นำเข้า PDF จาก D&D Beyond** ใช้ไฟล์ Export ที่มีช่องข้อมูลของชีต และตรวจค่าที่อ่านได้ก่อนกดบันทึก ตัวอ่านทำงานในเบราว์เซอร์ ข้อมูลชีตที่ผ่านการตรวจจะถูกส่งไปบันทึกเมื่อกดบันทึกชีต

อ่านคะแนนความสามารถทั้งหก, HP, AC, Initiative, Proficiency, Saving Throws, ทักษะ, การโจมตี, รายการอุปกรณ์ และข้อมูลการร่ายเวทหลัก เวทเสริมที่ขึ้นกับเงื่อนไขของอาวุธจะแสดงเป็นหมายเหตุ ช่อง Current HP ที่ว่างจะใช้ Max HP เป็นค่าเริ่มต้น PDF แบบสแกนหรือแบบที่ช่อง Widget ถูกลบจากไฟล์ต้องกรอกเอง

เปิดหัวข้อ **คำนวณค่าสถานะ D&D** เพื่อเลือกคำนวณ HP แบบค่าคงที่จาก Hit Die และ Constitution ของแต่ละคลาส คำนวณ AC จากเกราะ, DEX, โล่ และตัวปรับอื่น หรือเปิดสูตร Proficiency, Initiative และค่าสำหรับร่ายเวท การนำเข้าจะเริ่มด้วยค่าที่พิมพ์ใน PDF คุณจึงใช้ค่าที่ทอยเองหรือค่าจากความสามารถพิเศษได้ [การสร้างตัวละคร](https://www.dndbeyond.com/sources/dnd/br-2024/creating-a-character) · [เกราะและโล่](https://www.dndbeyond.com/sources/dnd/br-2024/equipment)

ดึงข้อมูลเป็น JSON จากไฟล์ได้ด้วยสคริปต์ สคริปต์ส่งออกคีย์ `sheet` และ `warnings` ทาง stdout

```sh
pnpm import:dndbeyond "path/to/character.pdf"
```

ระหว่างต่อสู้ให้ DM เลือกผู้ร่วมและทอย Initiative การโจมตีที่โดนสร้างผลทอยความเสียหายให้ DM ยืนยัน HP สำหรับเวทที่ให้เป้าหมายทอย Save ให้เลือกลูกเต๋าความเสียหาย ค่าความสามารถ และเป้าหมายจากชีตผู้ร่าย แล้วให้ผู้ควบคุมเป้าหมายทอยจากรายการผลทอย การใช้ช่องเวทและผลเฉพาะให้แก้จากชีตตามที่โต๊ะตกลง

เปิดห้องเดิมจาก URL ห้อง แล้วเข้าสู่ระบบด้วยบัญชีเดิมหรือเปิดจากโปรไฟล์เบราว์เซอร์เดิมหากเข้าห้องแบบ Guest ข้อมูล PostgreSQL และไฟล์แผนที่อยู่ใน Docker volumes `database` และ `maps` ใช้ `docker compose stop` เพื่อหยุดบริการโดยเก็บข้อมูลไว้ และใช้ `docker compose start` เพื่อกลับมาเล่นต่อ

## ตรวจสอบโค้ดและรอบการเล่น

ใช้ Node.js 24 และ pnpm ตามเวอร์ชันใน `package.json`

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm build
pnpm test
```

ชุดทดสอบ API ใช้ PostgreSQL แบบฝังเป็นค่าเริ่มต้น ตั้ง `BEHOLDER_TEST_URL=http://127.0.0.1:3000` เพื่อรันกับแอปจริงบน Docker โดยชุดทดสอบจะสร้างห้องเฉพาะของตัวเอง

ตั้ง `BEHOLDER_TEST_RESTART=1` เพิ่มเมื่อต้องการให้ชุดทดสอบรีสตาร์ตบริการ Compose ชุดนี้แล้วตรวจข้อมูลและแผนที่ที่บันทึกไว้ ให้รันก่อนเปิดโต๊ะจริงเพื่อไม่ให้เกมหยุดระหว่างเล่น

`pnpm test:browser` เปิด Microsoft Edge แบบ headless และจำลองสามที่นั่งกับแอปที่กำลังรัน ตั้ง `BEHOLDER_BROWSER` เป็นตำแหน่งไฟล์ของ Chrome หรือ Chromium หากเครื่องใช้เบราว์เซอร์อื่น

### Monster Manual

DM เปิด **☰ → Monster Manual** เพื่อค้นหามอนสเตอร์จาก SRD 5.2.1 จำนวน 330 รายการ กรองตาม CR แล้วเปิดดู stat block หรือ PDF ต้นฉบับตามหน้า เลือก **วางมอนสเตอร์ในฉาก** แล้วคลิกตำแหน่งบนกระดาน หรือกด **เพิ่มเป็นต้นแบบในห้อง** เพื่อแก้ไขและใช้ซ้ำ การโจมตีที่อ่านสูตรได้ใช้ดาเมจหลัก ส่วนดาเมจเสริม เงื่อนไข และความสามารถเฉพาะให้อ้างอิงข้อความในชีต

สำหรับมอนสเตอร์เพิ่มเติม เปิด **นำเข้า Stat Block ของคุณ** แล้ววางข้อความจากชีตที่มีสิทธิ์ใช้หรือ JSON เพื่อตรวจข้อมูลก่อนบันทึก เนื้อหาที่แจกพร้อมโครงการมาจาก [SRD 5.2.1](https://www.dndbeyond.com/srd) ภายใต้ [CC BY 4.0](public/data/SRD-LICENSE.txt) สร้างข้อมูลใหม่จาก PDF ภาษาอังกฤษด้วย `node scripts/import-srd-monsters.mjs path/to/SRD_CC_v5.2.1.pdf` จากโฟลเดอร์ Project
